Windows 命令入门学习手册

发表于2026-08-25|更新于2026-08-26|学习
|浏览量:

平时用 Windows 基本都是鼠标点，可真到要写脚本、要批量处理一堆文件的时候，还是命令行顺手。这份把 Windows 常用的命令整理了一下，同样按「想干什么」来排，不按命令名硬背。

它和 Linux 命令行版 是一套思路的分身——很多命令其实是同一个道理，这边会了那边几乎不用重学。

先提醒一句：Windows 现在有两套命令行。CMD 是旧的、默认开出来那个黑窗口；PowerShell 是新的、更强，用 powershell 或 pwsh 打开。这篇以 CMD 为主，PowerShell 不一样的地方我会单独标出来。

1. 基础概念

  • CMD：Windows 自带的命令行解释器（Command ），就是你按 Win+R → 输 cmd → 回车出来的黑窗口。
  • 提示符：C:\Users\你> —— 前面是当前所在路径，> 就相当于 Linux 的 $。
  • 命令结构：命令 [选项] [参数]，例如 dir /w C:\（/w 是选项，C:\ 是参数）。Windows 选项用 / 开头（不像 Linux 用 -）。

23. 快捷键与技巧

快捷键 作用
Tab 自动补全文件名
Ctrl+C 中断当前命令
Ctrl+V 在 CMD 里粘贴
Ctrl+H 在 CMD 里退格
↑ / ↓ 翻历史命令
F7 弹出历史命令列表
F3 重复上一条命令
F8 搜索历史命令
Win+R 快速打开运行框
Win+X 快捷菜单（管理员终端等）

常用 d: 和 cd /d 的组合：在 D 盘和 C 盘之间切，CMD 里跨盘符切目录要加 /d。

24. 推荐学习路线

  1. 先练熟高频命令：dir / cd / mkdir / copy / move / del / type / findstr / tasklist / taskkill / ipconfig / ping / systeminfo。
  2. 搞懂管道和重定向（| > >>），和 Linux 是同一个思想。
  3. 装 winget 包管理器，装 VS Code、装 git，把这些命令用起来。
  4. PowerShell 值得学：它比 CMD 强太多，很多 Linux 的用法（Sort-Object、Where-Object）在 PowerShell 里都有对应。
  5. 和 Linux 对照着学：同一件事，ls↔dir、cp↔copy、mv↔move、rm↔del、grep↔findstr、ps↔tasklist，一一对应着记最快。

学习原则：不要死记，多用 命令 /? 查；不知道命令就 where 找，记不住就 F7 翻历史。两套系统对照学，事半功倍。
