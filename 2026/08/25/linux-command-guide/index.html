1. 基础概念

  • Shell：你敲命令、和系统交互的程序（常见 bash、zsh）。
  • 提示符：user@host:~$ —— user 用户名、host 主机名、~ 当前目录（家目录）、$ 普通用户（# 是 root）。
  • 命令结构：命令 [选项] [参数]，例如 ls -l /home（-l 是选项，/home 是参数）。

7. 权限管理

ls -l 第一列形如 -rwxr-xr--，含义：

部分 含义
第 1 位 类型（- 文件、d 目录、l 链接）
第 2-4 位 属主（user）权限
第 5-7 位 属组（group）权限
第 8-10 位 其他人（other）权限

r=读(4) w=写(2) x=执行(1)。

23. 快捷键与技巧

快捷键 作用
Tab 自动补全文件名/命令
Ctrl+C 中断当前命令
Ctrl+Z 暂停当前命令
Ctrl+D 退出终端 / 发送 EOF
Ctrl+L 清屏
Ctrl+R 反向搜索历史命令
Ctrl+A / Ctrl+E 光标跳到行首 / 行尾
Ctrl+U 删除光标前整行
↑ / ↓ 上下翻历史命令
!! 重复上一条命令
!$ 上一条命令的最后一个参数

24. 推荐学习路线

  1. 先练熟高频 20 个：ls / cd / pwd / mkdir / cp / mv / rm / cat / less / head / tail / grep / find / chmod / sudo / ps / kill / df / free / ping。

  2. 搞懂管道和重定向（| > >>），这是理解 Linux 的关键。

  3. 学会看日志：tail -f + grep。

  4. 装一个 tldr 看命令的简洁示例（比 man 更友好）：

  5. 学点 Shell 脚本（第 19 章），自动化、部署都靠它。

  6. 做做练习：上 linuxsurvival.com 或 OverTheWire 的 bandit 闯关。

学习原则：不要死记，多用 --help / man 查；命令看不懂就 man 命令，记不住就 history | grep 找回来。
